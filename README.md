## 先分清一件事：你朋友说的"电脑版"是 Java 还是基岩

Minecraft 现在其实是两个游戏共用一块招牌。Java 版只有 Windows、macOS、Linux 桌面端；基岩版覆盖手机（Android、iOS）、Windows、Xbox、PlayStation 和 Switch。基岩版内部可以跨平台同服，Java 版默认只能和 Java 版玩，两边不通。

手机装的是基岩版，所以"电脑上那个"是哪种，直接决定你后面走哪条路：

- 电脑是微软商店那套（基岩版）→ 手机和电脑可以直接进同一个服，最省事
- 电脑是官网下载的 Java 版 → 需要给 Java 服务端装 GeyserMC + Floodgate 这套代理插件，手机基岩玩家才能进来
- 用官方 Realms 的话，Java 版和基岩版是两个独立订阅，买一个不能给另一个用

最常见的翻车场景就是这个：电脑上明明装了 Minecraft，手机输地址死活进不去。多数时候不是服务器的问题，是版本对不上。还有一种更隐蔽的——Windows 上同时装了商店版和 Java 版，你以为自己开的是 Java 服，其实进游戏的是基岩客户端。

### 固定计费和动态计费，别选错

这两个模式的差别比价格本身更重要。

**固定计费**就是传统月租，按配置和带宽收钱，不额外扣费，适合服务器长期开着、CPU 长期吃满的场景。

**动态计费**是低月租加 CPU 电费。基准线是 CPU 使用率 20%，低于 20% 视为不耗电，高出的部分按天结算，内存、硬盘这些不产生电费。空转的服务器几乎不额外花钱。

怎么选：服里几十人全天在线、CPU 长期在 50% 以上，用固定计费，省得每天看账单。只是每天晚上和朋友玩两三个小时，动态计费更划算——有教程作者在分享里提到，用动态计费和朋友每天开一两个小时，一天花费不到一元。这个数字因配置和地域而异，但量级可以感受一下。

6. 回到控制台复制"对外地址:端口"，这就是要发给朋友的连接地址

客户端怎么填：

- **Java 版**：多人游戏 → 添加服务器 → 地址填 IP，端口默认 25565
- **基岩版**：服务器 → 添加服务器 → 地址填 IP，端口默认 19132

版本必须和服务端一致。基岩版客户端输 Java 服的地址是连不上的，除非服务端做了协议转换。

## 手机基岩版进电脑的 Java 服，靠 GeyserMC

这是"手机和电脑联机"里最需要绕的一道弯。GeyserMC 负责把基岩版的协议翻译成 Java 服务端能听懂的话，Floodgate 负责免掉基岩玩家的 Java 账号。两个插件装完，原来的 Java 存档、插件、白名单都还在，手机、平板、Switch 可以进同一个世界。

两个必须知道的前提：

- 原版差异会露出来。红石行为、部分方块状态、背包和界面操作都可能有细微区别，少数插件和模组在基岩客户端上不工作
- 装了 Floodgate 之后服务端一般要关掉 online-mode 正版验证，权限和密码得靠白名单、登录插件、权限组来管，别裸奔

安卓上也有社区做的 Java 版启动器，能让手机直接跑 Java 客户端，但模组兼容性和性能要自己折腾，和基岩版走 Geyser 是两条完全不同的路。

## 常见问题，一次答完

**家里电脑开服不行吗？**
能开，但要过两关：路由器端口映射，和运营商给不给公网 IP。很多家庭宽带分到的是运营商的大内网地址，映射出去也没用；手机流量更干脆，运营商基本不允许。这是自建云服务器最实际的省事之处——独立 IP 加固定端口，地址发出去就能连，不用管你家的网络环境。

**2 核 4G 够用吗？**
按官方参考是纯净服 12+ 人。但你要是上 200 个 mod 的整合包，1 到 2 个人就跑满了。看玩法，不看人数。这也是为什么别一上来就买顶配，先用入门级跑一段时间，看 TPS 和内存曲线，再决定升不升。

**地址会不会变、会不会被封端口？**
云服务器的 IP 是固定的，重启不变。端口开放和映射在自己的控制台里操作，比家里路由器那套省心。
